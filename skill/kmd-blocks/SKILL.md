# Библиотека блоков КМД

Путь к библиотеке `LIB` указан в CLAUDE.md проекта (по умолчанию `C:/KMD_Blocks`).
Сервер MCP — `autocad-2026` (не путать с сервером AutoCAD 2023).

## 1. Найти блок — только через индекс
Не открывать DXF-файлы и не перебирать папки. Искать строкой в `LIB/catalog/index.csv`:
`grep -i "20Б1" LIB/catalog/index.csv`. Колонки (разделитель `;`):
`name;category;title_ru;gost;size;file;layer;insert_point;scale_mode;attrs;params;lib_ver`.
- `scale_mode=model` — вставлять в масштабе 1 (натура); `sheet` — масштаб = знаменатель масштаба чертежа.
- `layer` — слой вставки. `insert_point` — где точка вставки.
- Если нужного типоразмера нет, а есть семейство (пилот: `SEC_I_57837_<профиль>_WH<d>`,
  `HW_SET_7798_M<d>x<L>_G<пакет>`), сгенерировать блок: `python -m kmd_blocks.build` после
  добавления позиции в `kmd_blocks/build.py`, либо сообщить пользователю.

## 2. Подгрузить блок в чертёж
1. `block_list` — если имя уже есть, перейти к шагу 3.
2. `system_set_variable("ATTREQ", 0)` — чтобы AutoCAD не спрашивал атрибуты.
3. `system_run_command('_-INSERT "ИМЯ=LIB/dist/dxf/КАТ/ИМЯ.dxf" 0,0 1 1 0\n')` — путь с прямыми слешами.
4. Удалить эту временную вставку (`entity_list(type_filter="INSERT")` → последняя с именем ИМЯ → `entity_delete`).
5. `system_set_variable("ATTREQ", 1)`.
Если DXF не принимается — использовать `LIB/dist/dwg/...dwg` (см. LIB/docs/MCP_PILOT.md).

## 3. Вставить
`block_insert(name, x, y, scale_x, scale_y, rotation, attributes={...}, layer=<из индекса>)`.
Скрытые атрибуты (`GOST`, `PROFILE`, `MASS_M`, `BOLT`…) заполнены по умолчанию — не трогать.
Видимые (`POS`, `MARK`, `ELEV`…) — заполнять. Проверка: `block_get_attributes(handle)`.

## 4. Штамп и свойства проекта
- Шифр, Объект, Наименование документа, Стадия, Разработал, Проверил, ГИП, Н. контр., Дата,
  Организация — свойства чертежа: `drawing_properties_set`. В штамп выводятся полями на всех листах.
- Рамка `FullFrame_RUS` (динамический блок) на каждом листе: атрибуты ФОРМАТ, НАИМЕНОВАНИЕ_ЛИСТА,
  СТ, НОМЕР, К0ЛВ0 (цифры 0), ДОЛЖ_4/6, ФАМИЛИЯ_4–6. У вставок теги бывают с суффиксом
  (`НАИМЕНОВАНИЕ_ЛИСТА_001`) — сначала `block_get_attributes`, потом `block_set_attributes` теми же тегами.
- «Листов» (К0ЛВ0) заполняется только на первом листе.

## 5. Оформление
- Слои только из шаблона: контур `К_Контур`, тонкие `К_Контур_тонк`, оси `О_Оси`, размеры `Р_Размеры`,
  текст и выноски `А_Текст`, марки `А_Марки`, разрезы `А_Разрезы`, сварка `А_Сварка`, временное `Z_Вспомог`.
- Текст — стиль «ГОСТ 2.304» (ISOCPEUR). Стиль «ISOCPEUR» не использовать: в шаблоне он с высотой 50.
  Высота на листе 2.5/3.5/5 мм, в модели × знаменатель масштаба.
- Размеры — стиль `AG_KB` (засечки, текст 2.5), DIMSCALE = знаменатель масштаба. Малый размер:
  текст выносится на полку автоматически (DIMTMOVE=1). Для десятых долей — DIMDEC=1, разделитель «,».
- Болты в продольном разрезе — нерассечёнными; сечение проката — со штриховкой.

## 6. Правила
- Объекты Claude помечать XData `CLAUDE` (`entity_set_xdata`).
- Общий purge не запускать; листы шаблона не удалять.
- После вставки — `view_screenshot` и сверка. Серии > 20 объектов — сначала план пользователю.
- Динамические блоки пользователя (рамка, профили-«дин») MCP не настраивает и не находит по имени
  (вставки — анонимные `*U…`). Для черчения брать статичные блоки библиотеки.
