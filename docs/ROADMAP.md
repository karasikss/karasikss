# План работ

## Цель
Переносимая между проектами библиотека блоков КМД, которую Claude использует
для составления чертежей через Autocad-MCP, тратя минимум токенов на поиск и
вставку блоков.

## Исходные условия
- AutoCAD 2026, живой (COM-режим Autocad-MCP, Windows).
- Блоки генерируются кодом (Python + ezdxf) из таблиц ГОСТ — ручной отрисовки нет.
- Оформление: СПДС (ГОСТ Р 21.101-2026), КМД — ГОСТ 2.410; шрифт ISOCPEUR; слои — из шаблона пользователя;
  разрезы и виды — ГОСТ 2.305. Основная специализация — шумозащитные экраны (ШЗЭ).
- Размеры ГОСТ вносит Claude, пользователь выборочно сверяет.

## Анализ Autocad-MCP (что важно для библиотеки)
| Возможность | Инструмент | Вывод для нас |
|---|---|---|
| Вставка блока с атрибутами | `block_insert(name, x, y, scale, rotation, attributes)` | Основной способ. Работает только с блоками, уже определёнными в чертеже |
| Подгрузка блока из файла | `system_run_command("_-INSERT ИМЯ=путь.dwg ...")` (COM) | Подгружаем ровно нужный блок → нужен **один файл на блок** |
| Новый лист из шаблона | `drawing_new(template="путь.dwt")` | Шаблон КМД со слоями, стилями, рамками и частыми блоками |
| Блок из примитивов | `block_define(...)` | Запасной путь (дорого по токенам) |
| Чтение атрибутов | `block_get_attributes`, `data_extract`, `bom_extract` | Спецификация металлопроката строится из скрытых атрибутов |
| DXF → DWG | `drawing_open` + `drawing_save_as` / `drawing_export_dwg` (COM) | Сборку DWG выполняет AutoCAD пользователя |
| Стоимость каталога инструментов | `TOOL_PROFILE`, `TOOL_PACKS`, `DISCOVERY_MODE` | Рекомендуется `TOOL_PROFILE=lean` (~23k токенов вместо ~84k) или `DISCOVERY_MODE=search` |
| Готовые блоки | ISO-крепёж, рамки ISO 5457, штамп ISO 7200 | Не ГОСТ — наша библиотека закрывает этот пробел |

Ограничения: `(command ...)` в LISP через MCP запрещён; `-INSERT`, `ATTREQ` через
`system_run_command` разрешены. Пути к библиотеке должны входить в `ALLOWED_PATHS`.
Динамические блоки ни ezdxf, ни MCP не поддерживают → каждый типоразмер = отдельный блок.

## Архитектура
```
data/            таблицы ГОСТ (CSV) — источник истины
generator/       Python: таблица → геометрия → блоки
dist/            результат сборки (не правится руками)
  dxf/<категория>/<ИМЯ>.dxf   один блок = один файл
  dwg/<категория>/<ИМЯ>.dwg   после конвертации в AutoCAD
  KMD.dwt                      шаблон: слои, стили, рамки, частые блоки
  previews/<ИМЯ>.png
catalog/index.csv  одна строка на блок — Claude ищет grep-ом
skill/SKILL.md     инструкция Claude: поиск → доставка → вставка → проверка
tools/             скрипты конвертации DXF→DWG, установки skill
tests/             проверки геометрии, атрибутов, индекса
```

### Сценарий работы Claude
1. `grep` по `catalog/index.csv` (например `20Б1`, `M20`, `выноска`) → имя блока, файл, атрибуты, точка вставки.
2. `block_list` — есть ли блок в чертеже; если нет — `-INSERT ИМЯ=<lib>/dwg/...dwg` (вставка без размещения).
3. `block_insert` с атрибутами и масштабом листа.
4. `block_get_attributes` — проверка.

| 4 | Метизы | Болты (ГОСТ 7798, 7805, 32484.3), гайки (ГОСТ 5915, 32484.5), шайбы (ГОСТ 11371, 32484.6), фундаментные болты (ГОСТ 24379.1); обозначения по ГОСТ 21.502 + виды |
