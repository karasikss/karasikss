# Перечень блоков (актуализируемый)

Рабочий список. Колонки:
- **Очередь**: 1 — нужно для первого пилотного листа ШЗЭ, 2 — следом, 3 — по мере надобности.
- **Тип**:
  - `С` — статичный блок. Отдельный блок на каждый типоразмер, Claude вставляет его через MCP.
  - `Ф` — параметрическое семейство. Генератор строит блок под заданные размеры проекта.
  - `Д` — динамический блок пользователя. Только для ручной работы, MCP его параметрами не управляет.
- **Статус**: `есть` — блок уже есть у пользователя; `проверить` — есть, но нужна сверка с ГОСТ Р 21.101-2026; `сделать` — нужно сделать; `прислать` — пользователь пришлёт.
- **Виды**: П — план, Ф — фасад/вид, Р — разрез/сечение.
