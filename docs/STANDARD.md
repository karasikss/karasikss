# Стандарт блоков библиотеки КМД (черновик v0.2)

Обязателен для всех блоков. Генератор и тесты проверяют соответствие.

## 0. Нормативная база (проверено 22.10.2026)
- Оформление — СПДС: ГОСТ Р 21.101-2026 (оси, отметки, выноски, разрезы, узлы, основная надпись, формы 3–6).
- КМД — ГОСТ 2.410-68. ГОСТ 21.502-2016 — только для КМ.
- Линии — ГОСТ 2.303-68, шрифты — ГОСТ 2.304-81, виды и разрезы — ГОСТ 2.305-2008,
  размеры — ГОСТ 2.307-2011, сварка — ГОСТ 2.312-72, крепёж — ГОСТ 2.315-68.
- Шаблон пользователя `SP_Шаблон_РД.dwt` — эталон слоёв, стилей и рамок. Библиотека под него подстраивается, а не наоборот.

## 1. Формат и версии
- Исходник сборки — DXF (ezdxf), рабочий формат — DWG (сохраняет AutoCAD 2026, формат AutoCAD 2018).
- Один блок = один файл; имя файла = имя блока. Плюс шаблон `KMD.dwt`.
- Единицы чертежа — миллиметры (`$INSUNITS = 4`).
- Версия библиотеки — SemVer, хранится в индексе и в метаданных блока.

## 2. Имена блоков
Шаблон: `<КАТЕГОРИЯ>_<ПОДТИП>_<ГОСТ>_<РАЗМЕР>[_<ВИД>]`, только `A–Z 0–9 _ x .`, без кириллицы и пробелов.

| Категория | Пример | Что это |
|---|---|---|
| `SEC` | `SEC_I_57837_20B1`, `SEC_U_8240_16P`, `SEC_L_8509_75x6` | Сечения проката |
| `HW` | `HW_BOLT_7798_M20x60_SIDE`, `HW_NUT_5915_M20_TOP`, `HW_BOLT_21502_PERM` | Метизы и их условные обозначения |
| `ANN` | `ANN_LEADER_POS`, `ANN_SECTION_MARK`, `ANN_ELEV` | Знаки оформления |
| `WELD` | `WELD_LEADER_5264`, `WELD_SYM_SITE` | Сварные швы |
| `SHEET` | `SHEET_FRAME_A3`, `SHEET_TB_F3` | Рамки и основные надписи |
| `OBJ` | `OBJ_RIB_...` | Прочие объекты |

Кириллица в именах блоков ломается в путях, LISP и кодировках, поэтому русское наименование
хранится в индексе (`title_ru`) и в описании блока (его показывает палитра «Блоки»).
Существующие блоки пользователя с русскими именами («Отметка», «Обозн_узел» и др.) не переименовываются,
пока не пройдут сверку; в индекс они попадают под своими именами.

### Динамические блоки
Autocad-MCP не меняет параметры динамических блоков (размер, видимость, отражение) и не находит
их вставки по имени: AutoCAD хранит такие вставки как анонимные блоки `*U…`.
Поэтому:
- блоки, которые вставляет Claude, — статичные: один типоразмер = один блок, либо семейство,
  которое генератор строит под размеры проекта;
- динамические блоки пользователя остаются для ручной работы (тип `Д` в перечне);
- если управление динамикой понадобится, его добавят отдельным инструментом MCP через COM
  (`GetDynamicBlockProperties`, `EffectiveName`).
Транслитерация в размерах: Б→B, Ш→SH, К→K, П→P, У→U.

## 3. Геометрия
- Сечения проката: натуральная величина 1:1, по таблице ГОСТ, включая радиусы скруглений и уклон полок.
  Точка вставки — центр тяжести сечения; оси симметрии/центра тяжести — внутри блока.
- Метизы: натуральная величина 1:1. Точка вставки — ось на опорной плоскости (под головкой у болта).
- Знаки оформления и рамки: размеры даны **для листа** (мм на бумаге). При вставке
  масштаб = знаменатель масштаба чертежа (1:20 → 20). Аннотативность не используется (MCP её не поддерживает).
- Полилинии замкнутые, без наложений и нулевых сегментов; дуги как дуги (bulge), а не аппроксимация.

## 4. Слои, цвета, линии
- Геометрия блока — на слое `0`, цвет/тип/вес линии `ПоБлоку`: блок получает свойства слоя, на который вставлен.
- Исключение: осевые линии внутри блока — тип линии `ЦЕНТР` (CENTER2), вес 0.18, остальное ПоБлоку.
- Вес линий по ГОСТ 2.303 задают слои шаблона, а не блоки.
- Слои — из шаблона `SP_Шаблон_РД.dwt`, новые слои библиотека не создаёт:

| Слой | Вес | Что на нём |
|---|---|---|
| К_Контур | 0.50 | Видимый контур конструкций |
| К_Контур_тонк | 0.18 | Тонкие линии конструкций |
| К_Невидимый | 0.25 | Невидимый контур (ACAD_ISO02W100) |
| К_Схема | 0.50 | Геометрические схемы |
| К_Примыкающие | 0.18 | Примыкающие конструкции, фундаменты (ACAD_ISO05W100) |
| О_Оси / О_Центровые | 0.18 | Оси (ACAD_ISO04W100) |
| Р_Размеры / Р_Отметки | — | Размеры, отметки |
| А_Марки / А_Текст / А_Разрезы (0.70) / А_Узлы / А_Сварка / А_Крепёж | — | Оформление |
| Ш_Штриховка | — | Штриховки |
| Л_Обрыв / Л_Рамка (0.50) / Л_ВЭкраны | — | Лист |
| Z_Вспомог | — | Временное (не печатается) |

- Слой вставки каждого блока указан в индексе (колонка `layer`).
- Осевые линии внутри блока — тип ACAD_ISO04W100, остальное ПоБлоку.

## 5. Текст и атрибуты
- Шрифт ISOCPEUR (стиль шаблона пользователя), коэффициент сжатия 1.0, наклон по стилю.
  Высота по ГОСТ 2.304: 2.5 / 3.5 / 5 / 7 мм на листе (номера осей и узлов — 5, марки — 3.5–5, прочий текст — 2.5–3.5).
- Теги атрибутов — латиница UPPER_CASE; подсказки (prompt) — по-русски.
- Единый словарь тегов:

| Тег | Назначение | Видимый |
|---|---|---|
| `POS` | Номер позиции | да |
| `MARK` | Марка элемента/узла | да |
| `ELEV` | Отметка уровня | да |
| `AXIS` | Обозначение оси | да |
| `TEXT1`, `TEXT2` | Надписи над/под полкой | да |
| `GOST` | Обозначение стандарта | нет |
| `PROFILE` | Профиль, например `20Б1` | нет |
| `STEEL` | Марка стали | нет |
| `MASS_M` | Масса 1 м, кг | нет |
| `LIB_ID`, `LIB_VER` | Идентификатор и версия блока в библиотеке | нет |

- Скрытые атрибуты (`GOST`, `PROFILE`, `STEEL`, `MASS_M`) нужны, чтобы собирать спецификацию через `data_extract`.

## 6. Индекс `catalog/index.csv`
Одна строка на блок, UTF-8, разделитель `;`. Колонки:
`name;category;title_ru;gost;size;file;layer;insert_point;scale_mode;attrs;params;lib_ver`

- `scale_mode`: `model` (1:1, натура) или `sheet` (умножать на знаменатель масштаба).
- `attrs`: теги через запятую, обязательные помечены `*` (например `POS*,TEXT1`).
- `params`: ключевые размеры (`h=200,b=100,s=5.6,t=8.5`).

Индекс — единственный файл, который Claude читает для поиска, поэтому строки короткие, без описаний длиннее 60 символов.

## 7. Правила работы Claude в чертеже
- Объекты, созданные Claude, помечаются XData `CLAUDE`; временные — на слое `Z_Вспомог`.
- Общий `purge` в шаблоне не запускать.
- После вставки — `view_screenshot` и сверка; серии больше 20 объектов — сначала план.

## 8. Качество (проверяется тестами)
- Блок открывается, `audit` проходит без ошибок.
- Габариты сечения совпадают с таблицей ГОСТ (допуск 0.01 мм).
- Каждый блок есть в индексе, и каждая строка индекса указывает на существующий файл.
- Набор атрибутов совпадает с колонкой `attrs`.
- Для каждого блока есть PNG-превью.
